# Data and saved split

`olivetti_split_seed_26006.npz` contains fixed train/validation/test row indices for the canonical 400-image Olivetti Faces ordering. The split is identity-stratified: 6 train, 2 validation, and 2 test images per each of 40 identities. Seed: 26006. The image dataset itself is fetched by scikit-learn and is not redistributed here.
